# AssertX AI prompts

Ready-to-paste prompts for coding agents (Cursor, Claude Code, Copilot Chat, etc.) when working with AssertX in a consumer service.

| Prompt | Use when |
|--------|----------|
| [integrate-assertx.md](integrate-assertx.md) | Adding AssertX to a Maven/Gradle Java service (dependency, ITMain, `api-testing.yml`, mocks) |
| [write-assertx-tests.md](write-assertx-tests.md) | Writing Cucumber features, custom steps, and downstream mocks |

## How to use

1. Open the prompt file for your task.
2. Copy the fenced prompt block into your agent chat.
3. Fill in any placeholders (for example the endpoints to test).
4. Optionally `@`-mention this repo’s [README](../README.md) or the target service’s controllers / existing features for context.

These prompts complement the human docs in the root [README](../README.md); they do not replace Integration Steps.
